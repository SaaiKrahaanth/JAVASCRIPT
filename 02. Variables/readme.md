### **Variables in JavaScript**  

Variables are **containers for storing data** in a program. They allow data to be reused and manipulated efficiently.  

Key points:  
✅ **Declaring Variables:**  
   - `var` (old, avoid using)  
   - `let` (for reassignable values)  
   - `const` (for constant values)  

✅ **Uninitialized Variables** store `undefined` by default.  

✅ **Assignment Operators** (`+=`, `-=`, `*=`, `/=`) simplify mathematical operations.  

✅ **String Concatenation:** `+` joins strings (e.g., `'Hello' + ' World'`).  

✅ **Template Literals:** Use **backticks** `` ` `` and `${}` for easy string interpolation (e.g., `` `Hello, ${name}!` ``).  

✅ **typeof Operator** returns the data type of a value (`typeof 42 → 'number'`).  

Variables are fundamental in JavaScript and essential for dynamic programming! 🚀
