### **Introduction to JavaScript**  

JavaScript (JS) is a versatile programming language used to create **interactive and dynamic web pages**. It is a core web technology alongside **HTML** and **CSS**, enabling features like animations, form validation, and real-time updates.  

Key concepts include:  
✅ **Logging output** with `console.log()`  
✅ **Comments** (`//` for single-line, `/* */` for multi-line)  
✅ **Data types** (Numbers, Strings, Booleans, etc.)  
✅ **Operators** for calculations (`+`, `-`, `*`, `/`, `%`)  
✅ **Objects & Methods** (e.g., `'Hello'.length`, `'hello'.toUpperCase()`)  
✅ **Built-in objects** like `Math`  

JavaScript is widely used for both **frontend** (React, Vue) and **backend** (Node.js) development, making it essential for modern web applications. 🚀
