# 🏁 Race Day - JavaScript Project

This project simulates a runner registration and scheduling system for Codecademy's annual race event. Runners are assigned a **race number** and **start time** based on age and registration status using JavaScript control flow.

---

## 📚 Project Objectives

- Practice JavaScript conditionals (`if`, `else if`, `else`)
- Utilize logical operators (`&&`, `||`)
- Work with `Math.random()` and `Math.floor()`
- Apply string interpolation
- Simulate real-world logic for race registration

---

## 🧠 Logic Summary

- 🧑‍🦱 **Adult Runners (age > 18):**
  - Registered early → Race number ≥ 1000 and race at **9:30 am**
  - Registered late → Race number < 1000 and race at **11:00 am**
- 🧒 **Youth Runners (age < 18):**  
  - Always race at **12:30 pm**
- 🧑‍🎓 **Exactly 18 years old:**  
  - Must check in at the **registration desk**
