# 🎱 Magic Eight Ball

A fun JavaScript project that simulates a Magic Eight Ball to answer user questions with randomized, fortune-telling responses.

## 🚀 Project Description

The **Magic Eight Ball** is a simple command-line program that:
- Greets the user.
- Accepts a question from the user.
- Generates a random number between 0 and 7.
- Uses the number to provide a random Magic Eight Ball response.
- Outputs the answer to the console.

This project demonstrates the use of variables, conditionals, `Math.random()`, `Math.floor()`, template literals, and `switch` statements.

## 📁 How to Run

1. Make sure you have **Node.js** installed.
2. Save the code in a file named `magicEightBall.js`.
3. Run the file using the terminal:
   ```bash
   node magicEightBall.js
   ```
